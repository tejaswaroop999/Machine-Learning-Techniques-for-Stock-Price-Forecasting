# Machine Learning Techniques for Stock Price Forecasting

An academic machine-learning project exploring approaches for **stock-price forecasting** using Python and Jupyter Notebook.

This repository contains the project notebook together with supporting academic documentation.

## Repository contents

```text
DATASETS/
├── Stock_market_prediction_4th_yr_code.ipynb
├── 1-4 chapter.docx
├── 5-8 chapter.docx
└── coverpage.docx
```

## What this project demonstrates

- exploratory machine-learning workflow in Jupyter
- time-series / stock-market forecasting experimentation
- data preparation and model experimentation
- documenting an ML project as part of an academic study

## Main notebook

The implementation is available in:

`DATASETS/Stock_market_prediction_4th_yr_code.ipynb`

Open it with Jupyter Notebook, JupyterLab, VS Code, or Google Colab to review and run the analysis.

## Run locally

```bash
git clone https://github.com/tejaswaroop999/Machine-Learning-Techniques-for-Stock-Price-Forecasting.git
cd Machine-Learning-Techniques-for-Stock-Price-Forecasting
jupyter notebook
```

Then open:

`DATASETS/Stock_market_prediction_4th_yr_code.ipynb`
